1. Alphabets & Formal Definitions

Definition

An alphabet is a finite, non-empty set of symbols.

  • We use the symbol ∑ (sigma) to denote an alphabet.

Examples of Alphabets:

  • Binary: ∑ = {0, 1}
  • All lower case letters: ∑ = {a, b, c,.. z}
  • Alphanumeric: ∑ = {a-z, A-Z, 0-9}
  • Numeric: ∑ = {0, 1, 2, 3,.. 9}
  • DNA molecule letters: ∑ = {A, C, G, T}
  • Initials of my name: ∑ = {A, B, G}
  • Octal numbers: ∑ = {0, 1, 2, 3, 4, 5, 6, 7}
  • Arbitrary: ∑ = {a, b, c}

2. Strings and String Operations

Definition

A string or word is a finite sequence of symbols chosen from ∑.

  • Empty string: ε (or "epsilon").
  • Length of a string w: Denoted by "|w|", is equal to the number of (non-ε) characters in the string.

Length Examples (∑ = {0, 1}):

  • x = 010100 ⇒ |x| = 6
  • x = 01ε 0ε 1ε 00ε ⇒ |x| = 6
  • y = 111 ⇒ |y| = 3

Concatenation of Strings:

xy = concatenation of two strings x and y:

  • x = 010100; quad y = 111
  • xy = 010100111 ⇒ |xy| = 9

3. Powers of an Alphabet (∑k, ∑*, ∑+)

Let ∑ be an alphabet:

  • ∑k: The set of all strings of length k.

If ∑ = {0, 1}:

  • ∑1: {0, 1}
  • ∑2: {01, 00, 10, 11}
  • ∑3: {000, 111, 010, 101, 001, 100, 011, 110}
  • ∑4: {0000, 1111, 0101, 1010, 0011, 1100, …}

Kleene Star (∑*) vs. Positive Closure (∑+):

  • ∑* (Kleene Star):
    ∑* = ∑0 ∪ ∑1 ∪ ∑2 ∪ …
    ∑* = {ε, 0, 1, 00, 01, 10, 11, 000, 001, 010, …}
  • ∑+ (Positive Closure):
    ∑+ = ∑1 ∪ ∑2 ∪ ∑3 ∪ …
    ∑+ = {0, 1, 00, 01, 10, 11, 000, 001, 010, …}

4. Languages & Grammars

Chomsky's Definitions (1959)

  • Languages: “A language is a collection of sentences of finite length all constructed from a finite alphabet of symbols”
  • Grammars: “A grammar can be regarded as a device that enumerates the sentences of a language” - nothing more, nothing less
  • Citation: N. Chomsky, Information and Control, Vol 2, 1959

Grammar & Language Relationships

  • An alphabet is a set of symbols: {0, 1}
  • Languages (or “words”) are strings of symbols: {0, 1, 00, 01, 10, 1…}
  • A language is a set of sentences: L = {0n 1n : n ≥ 0} = {ε, 01, 0011, …}
  • A grammar is a finite list of rules defining a language. Example:
    S → 0A      B → 1B
    A → 1A      B → 0F
    A → 0B      F → ε

Formal Definition of Language

L is said to be a language over alphabet ∑, only if L ⊆ sum*.

→ This is because ∑* is the set of all strings (of all possible length including 0) over the given alphabet ∑.

Language Examples:

  1. Let L be the language of all strings consisting of n 0’s followed by n 1’s:
    L = {ε, 01, 0011, 000111, …}
  2. Let L be the language of all strings with equal number of 0’s and 1’s:
    L = {ε, 01, 10, 0011, 1100, 0101, 1010, 1001, …}
Empty Language

Ø denotes the Empty language.

• Let L = {ε}; Is L = ∅? (No, {ε} contains the empty string of length 0, whereas ∅ contains no strings at all).

5. The Membership Problem

Problem Definition

Given a string w ∈ Σ* and a language L over Σ, decide whether or not w ∈ L.

Worked Example:

  • Let w = 100011
  • Length: |w| = 6
  • Question: Is w ∈ the language of strings with equal number of 0s and 1s?
  • Answer: YES! (Contains three 0s and three 1s).

🏛️ Pillar 1: Core Terminology & High-Yield Keyword Recall Grid

Essential academic definitions and exact formal automata vocabulary required for exam question recall.

Alphabet (Σ)

Alphabet (Σ): A finite, non-empty set of symbols (e.g., Binary {0, 1}, Lowercase {a..z}, DNA {A, C, G, T}, Octal {0..7}, Alphanumeric {a..z, A..Z, 0..9}).

Symbol

Symbol: An individual atomic character, letter, or digit belonging to an alphabet Σ (e.g., 0 or 1 in Binary).

String / Word (w)

String (Word): A finite sequence of symbols chosen from an alphabet Σ (e.g., 01011 over {0, 1}).

Empty String (ε / λ)

Empty String (ε or λ): The unique string containing zero symbols. Its length is strictly |ε| = 0. It serves as the identity element under concatenation (wε = εw = w).

String Length (|w|)

String Length (|w|): The number of non-ε symbol positions in string w (e.g., |010100| = 6; |01ε0ε1ε00ε| = 6).

String Concatenation

Concatenation (xy): The string formed by appending string y directly after string x. Length is additive: |xy| = |x| + |y|.

Alphabet Power (Σk)

Alphabet Power (Σk): The set of all strings of length exactly k formed from symbols in Σ. Cardinality is |Σk| = |Σ|k.

Base Power (Σ⁰)

Base Power (Σ⁰): Σ⁰ = {ε} (the set containing solely the empty string of length 0) for ANY non-empty alphabet Σ.

Kleene Star (Σ*)

Kleene Star (Σ*): The infinite set of all finite strings over Σ, including the empty string ε: Σ* = Σ⁰ ∪ Σ¹ ∪ Σ² ∪ … = Σ⁺ ∪ {ε}.

Positive Closure (Σ⁺)

Positive Closure / Kleene Plus (Σ⁺): The infinite set of all non-empty strings over Σ: Σ⁺ = Σ¹ ∪ Σ² ∪ Σ³ ∪ … = Σ* \ {ε}.

Formal Language (L)

Formal Language (L): Any set of sentences/strings constructed from a finite alphabet. Formally, L ⊆ Σ* for any language over Σ.

Empty Language (∅)

Empty Language (∅): The language containing zero strings. Cardinality |∅| = 0.

Empty String Language ({ε})

Empty String Language ({ε}): The language containing exactly 1 string (the empty string ε of length 0). Cardinality |{ε}| = 1. Note: ∅ ≠ {ε}.

Formal Grammar (G)

Formal Grammar: A generative mathematical device (Chomsky, 1959) that enumerates/generates all sentences belonging to a language.

Grammar 4-Tuple

Grammar 4-Tuple G = (V, T, P, S): V = Variables / Non-terminals, T = Terminals (Σ), P = Production rules, S = Start symbol (S ∈ V).

The Membership Problem

The Membership Problem: Given string w ∈ Σ* and formal language L, decide algorithmically whether w ∈ L (YES/NO).

Deterministic Finite Automaton (DFA)

DFA 5-Tuple M = (Q, Σ, δ, q₀, F): Q = Finite states, Σ = Alphabet, δ = Transition function (Q × Σ → Q), q₀ = Start state, F = Accepting states (F ⊆ Q).

Transition Function (δ)

Transition Function (δ): The core state-transition mapping δ: Q × Σ → Q. In a valid DFA, δ(q, a) must be uniquely defined for every state q and symbol a.

📐 Pillar 2: Formula & Quantitative Calculation Reference Cards

1. Alphabet Power Cardinality
|Σk| = |Σ|k  |  Σ⁰ = {ε}

When to Use / Verbalization: Calculating the total number of distinct strings of length k constructible from alphabet Σ.

Plain English Meaning: The set size scales exponentially with string length k based on alphabet size |Σ|.

💡 Exam Problem: For binary alphabet Σ = {0, 1}, compute |Σ⁰|, |Σ²|, and |Σ⁴|.
Solution: |Σ⁰| = 2⁰ = 1 ({ε}); |Σ²| = 2² = 4 ({00,01,10,11}); |Σ⁴| = 2⁴ = 16 strings.
🗣️ How to Read in English
Read as: "Sigma to the power k is the set of all strings of length k with size equal to alphabet size raised to k. Sigma to the power zero equals the singleton set containing empty string epsilon."
2. Kleene Star & Plus Set Identities
Σ* = Σ⁺ ∪ {ε}  |  Σ⁺ = Σ* \ {ε}

When to Use / Verbalization: Expressing infinite string closures. Kleene Star contains all finite strings including ε (length ≥ 0); Kleene Plus contains all non-empty strings (length ≥ 1).

Plain English Meaning: Adding the empty string ε to Σ⁺ gives Σ*; removing ε from Σ* gives Σ⁺.

💡 Exam Problem: Is ε an element of Σ⁺ for Σ = {a, b}?
Solution: NO. ε ∉ Σ⁺ because all words in Σ⁺ have length |w| ≥ 1. However, ε ∈ Σ*.
🗣️ How to Read in English
Read as: "Sigma star includes the empty string epsilon; Sigma plus excludes the empty string."
3. String Length & Concatenation Axioms
|ε| = 0  |  |uv| = |u| + |v|  |  |uk| = k · |u|

When to Use / Verbalization: Computing string lengths under concatenation and empty string insertions. Inserting ε does not change string length.

Plain English Meaning: The empty string has 0 length and acts as an identity element in concatenation.

💡 Exam Problem: Find the length of string w = 01ε0ε1ε00ε.
Solution: Non-ε characters are 0, 1, 0, 1, 0, 0 → |w| = 6.
🗣️ How to Read in English
Read as: "The length of empty string epsilon is zero. Concatenation adds lengths. Repeating string u k times multiplies its length by k."
4. String Reversal & Involution Laws
(uv)R = vRuR  |  (uR)R = u  |  εR = ε

When to Use / Verbalization: Inverting concatenated strings. The reversal of uv is the reversal of v followed by reversal of u.

Plain English Meaning: Reversal flips concatenation order; reversing twice restores the original word.

💡 Exam Problem: Given u = 01 and v = 100, calculate uv and (uv)R.
Solution: uv = 01100 → (uv)R = 00110 = vRuR = (100)R(01)R = 001 · 10 = 00110.
🗣️ How to Read in English
Read as: "Reversing u-v reverses the order of symbols (v-reversed then u-reversed). The reversal of epsilon is epsilon."
5. Distinct Substring Count (with ε)
Nsubstrings = [n(n + 1) / 2] + 1

When to Use / Verbalization: Calculating the maximum number of distinct substrings in a string of length n (assuming all characters are distinct).

Plain English Meaning: Sum of substrings of lengths 1 to n plus 1 for the empty string ε.

💡 Exam Problem: How many distinct substrings are contained in w = abc (n = 3)?
Solution: [3(4)/2] + 1 = 6 + 1 = 7 substrings: {ε, a, b, c, ab, bc, abc}.
🗣️ How to Read in English
Read as: "The maximum distinct substrings in a string of length n equals n times n plus one over two, plus one for the empty string."
6. Formal DFA 5-Tuple & Grammar 4-Tuple
M = (Q, Σ, δ, q₀, F)  |  G = (V, T, P, S)

When to Use / Verbalization: Formal mathematical specification of Deterministic Finite Automata and Generative Grammars.

Plain English Meaning: DFA defines recognizer machine; Grammar defines generative string production rules.

💡 Exam Problem: Specify the DFA 5-tuple for an On/Off toggle switch with input Push.
Solution: Q = {off, on}, Σ = {Push}, δ(off, Push) = on, δ(on, Push) = off, q₀ = off, F = {on}.
🗣️ How to Read in English
Read as: "A Deterministic Finite Automaton M is defined by the 5-tuple of states Q, alphabet Sigma, transition function delta, start state q-zero, and accept states F; a formal grammar G is defined by the 4-tuple of variables V, terminals T, production rules P, and start symbol S."

⚠️ Pillar 4: Common Exam Pitfalls, Fallacies & Trap Alerts

Crucial exam traps regarding empty set vs empty string, length invariances, non-commutativity, and DFA completeness.

⚠️ Empty Set vs Empty String Trap

Fallacy: ∅ = {ε} because both represent "nothing".
Truth: ∅ ≠ {ε}! ∅ is the empty language containing 0 strings (|∅| = 0). {ε} is a language containing 1 string (the empty string ε, where |ε| = 0). Furthermore, L · ∅ = ∅, while L · {ε} = L.

⚠️ ε Invariance in String Length

Fallacy: Inserting ε increases string length by the number of ε symbols inserted.
Truth: ε NEVER increases string length! Because |ε| = 0, |01ε0ε1ε00ε| = |010100| = 6. ε is the identity element under concatenation (wε = εw = w).

⚠️ Non-Commutativity of Concatenation

Fallacy: String concatenation is commutative (uv = vu).
Truth: Concatenation is generally NON-COMMUTATIVE! For u = 01 and v = 100, uv = 01100 ≠ vu = 10001. It is only commutative if u and v are powers of the same string or if one is ε.

⚠️ Reversal Order Inversion Trap

Fallacy: (uv)R = uRvR.
Truth: (uv)R = vRuR! Reversing a concatenated string inverts the concatenation order of the operands. For u = 01 and v = 100: (uv)R = 00110 = (100)R(01)R = 001 · 10.

⚠️ Universal Language Subset Axiom

Fallacy: A language can contain strings with symbols outside its defining alphabet Σ.
Truth: L ⊆ Σ* holds universally! By formal definition, every language L over Σ is strictly a subset of Σ*. Any string containing external symbols does not belong to Σ* and cannot belong to L.

⚠️ DFA Transition Completeness Rule

Fallacy: In a DFA, a state can omit transitions for symbols it does not accept.
Truth: A DFA MUST BE TOTAL! The transition function δ: Q × Σ → Q must define exactly one transition for EVERY state q ∈ Q and EVERY alphabet symbol a ∈ Σ. Unaccepted inputs must transition to an explicit dead/trap state.
