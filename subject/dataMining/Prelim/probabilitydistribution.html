PART 1: Foundations: What a Distribution Is

Before studying specific distributions, we need the shared language: notation, mean, variance, standard deviation, and the difference between discrete and continuous data.

1.1 What Is a Probability Distribution?

Definition

A probability distribution shows the possible values a variable can take and how frequently they occur.

Notation You Will Use Everywhere

  • Uppercase Y: the actual outcome of an event (the random variable).
  • Lowercase y: one specific possible outcome.
  • P(Y=y) or simply P(y): the probability that the outcome equals a particular value y. This is called the probability function.
Example

Let Y be the number of red marbles drawn from a bag. Then the probability of drawing exactly five red marbles is written P(Y=5), or just P(5).

How Probabilities Are Constructed

With a finite number of outcomes, we record the frequency of each unique value and divide by the total number of elements in the sample space.

With infinitely many outcomes, this is impossible—there are too many values to count.

Example: the time it takes for code to run. Any measurement (seconds, milliseconds, nanoseconds) can always be split in half for more precision, so no smallest unit exists. This is why continuous distributions need different tools, which we cover in Part 3.

1.2 The Two Defining Characteristics: Mean and Variance

Every distribution—finite or infinite—is defined using two characteristics:

Characteristic Meaning Population symbol Sample symbol
Mean The average value of the distribution μ (mu) x-bar
Variance How spread out the data is—measured by how far values sit from the mean σ² (sigma-squared) s²

POPULATION VS SAMPLE

Population data = all the data. Sample data = just a part of it. The same data set can be both: surveying one whole department gives population data for the department, but only a sample of the whole company. Sample data uses different notation (x-bar and s²).

Standard Deviation: Making Variance Interpretable

Variance has one flaw: it is measured in squared units (seconds², kg², and so on), which usually has no direct interpretation. The fix is a third characteristic:

Definition

Standard deviation is the positive square root of variance. Symbols: σ for a population, s for a sample. It is measured in the same units as the mean, so we can interpret it directly—which is why it is often preferred.

A key idea used throughout the course: any value between μ-σ and μ+σ falls within one standard deviation of the mean. The more congested the middle of the distribution, the more data falls inside that interval. The less data inside it, the more dispersed the data is.

Formula
σ² = E[(Y - μ)²] = E(Y²) - μ²
Variance (σ²) = Expected value of squared deviations from the mean (μ) = Expected value of Y² minus squared mean

The constant relationship between mean and variance, valid for any distribution. Specific distributions give us much more precise shortcut formulas.

1.3 Discrete vs Continuous: The Big Split

Feature Discrete Continuous
Outcomes Finitely many distinct outcomes Infinitely many consecutive outcomes
Examples Rolling a die, picking a card Time and distance in track and field
Represented by Table, graph, or formula Graph of a curve (PDF)—a table is impossible
Graph looks like Separate, unconnected bars A smooth curve

Defining a Distribution: Standard Notation

We write the variable name, then the tilde sign (~), then a capital letter for the distribution type, and finally the key characteristics in parentheses (usually mean and variance, but this varies by type).

Example

X ~ N(μ, σ²) reads as: "Variable X follows a normal distribution with mean μ and variance σ²."

Working With Discrete Distributions

  • Every unique outcome must have a probability assigned to it (think of a dartboard—each region's probability depends on how big its interval is).
  • To find the probability of an interval, simply add up the probabilities of all values inside it. Example: P(three spades or fewer) = P(0) + P(1) + P(2) + P(3).
  • A useful peculiarity of discrete events: P(Y ≤ y) = P(Y < y+1). "Three spades or fewer" is exactly the same as "fewer than four spades."

PART 2: Discrete Distributions

Four key distributions for events with countable outcomes: Uniform, Bernoulli, Binomial, and Poisson.

2.1 Uniform Distribution: All Outcomes Equally Likely

NOTATION: X ~ U(a,b)—for example, X ~ U(3,7) reads "X follows a discrete uniform distribution ranging from 3 to 7."

When it applies: events where all outcomes have equal probability (also called equiprobable outcomes).

Examples

Rolling a standard six-sided die—every value from 1 to 6 has probability 1/6, so the graph is six equally tall bars. Also: many gambling events, or choosing between three identical chocolate bars a friend offers you.

KEY LIMITATION: Because all outcomes are equally likely, the mean and variance are uninterpretable and have no predictive power. For a die, the mean is 3.5 and the variance is 105/36—but neither value tells you anything useful about what will happen next.

2.2 Bernoulli Distribution: One Trial, Two Outcomes

NOTATION: X ~ Bern(p)—"X follows a Bernoulli distribution with probability of success equal to p."

When it applies: any event with one trial and exactly two possible outcomes—a coin flip, a single true/false quiz question, a two-party vote. Any two-outcome event can be transformed into a Bernoulli event by assigning one outcome to be "true" and the other "false," even if the outcomes are not equally likely.

Conventions:

  • The graph is just two bars: one rising to p, the other to 1-p.
  • We usually denote the higher probability as p, and assign the value 1 to that favored outcome. That way the expected value expresses the likelihood of the favored event.
  • Expected Value: E(X) = p
  • Variance: σ² = p(1-p)
Worked Example: THE UNFAIR COIN

A weighted coin lands on tails 60% of the time. Assign tails = 1, so p = 0.6. Expected value: E(X) = 0.6. Variance: 0.6 × 0.4 = 0.24.

2.3 Binomial Distribution: Repeating the Bernoulli Trial

NOTATION: X ~ B(n,p)—for example, B(10,0.6) reads "X follows a binomial distribution with 10 trials and a 0.6 likelihood of success on each individual trial." A Bernoulli distribution is simply a binomial with a single trial: Bern(p) = B(1,p).

The core idea: binomial events are a sequence of identical Bernoulli events.

INTUITION: A surprise pop quiz has 10 true/false questions you haven't prepared for. Guessing one question is a Bernoulli event. Guessing the entire quiz is a binomial event. The Bernoulli expected value tells you which outcome to expect on a single trial; the binomial expected value tells you how many times to expect that outcome over all trials.

The graph: for n trials, there are n+1 bars—one for each possible count from 0 to n. (Two flips of a coin → three bars: 0, 1, or 2 tails.)

Formula
P(y) = C(n, y) · py · (1 - p)n - y
Binomial Probability of y successes in n trials:
• C(n, y) = Combinations (ways to choose y successes out of n trials)
• py = Probability of success raised to power of successes
• (1 - p)n - y = Probability of failure raised to power of failures

C(n,y) = the number of combinations of picking y elements out of n. This is why combinatorics is a fundamental part of probability.

Worked Example: THE STOCK PRICE

You own one General Motors stock. Historically, there is a 60% chance the price goes up on any given day and 40% it drops. What is the probability of exactly 3 increases in a 5-day work week?

Plug in y = 3, n = 5, p = 0.6: P(3) = C(5,3) × 0.6³ × 0.4² = 10 × 0.216 × 0.16 = 0.3456 (34.56%).

E(X) = n · p | Variance: σ² = n · p · (1-p)

2.4 Poisson Distribution: How Often in an Interval?

NOTATION: Y ~ Po(λ)—"Y follows a Poisson distribution with lambda equal to 4." Lambda (λ) is the single parameter.

When it applies: when we know how often an event occurs on average over a specific interval of time or distance, and we want the likelihood of a particular frequency. It answers: "how unusual is this frequency for this interval?"

Examples

A firefly lights up 3 times per 10 seconds on average—how likely is it to light up 8 times in 20 seconds? Or: a basketball player averages 35 points per game—how likely is he to score exactly 12 points in the first quarter?

The graph: starts from zero (an event can't happen a negative number of times) but has no upper cap on how many times it could occur.

Formula
P(y) = (λy · e-λ) / y!
Poisson Probability of y occurrences in an interval:
• λ (lambda) = Average rate of occurrence per interval
• e = Euler's constant (≈ 2.71828)
• y! = Factorial of y (e.g. 3! = 3 × 2 × 1 = 6)
Worked Example: STUDENT QUESTIONS

Your online course usually gets about 4 questions per day (λ=4). Yesterday students asked 7. How likely was that exact number?

P(7) = 4&sup7; × e&supmin;&sup4; / 7! = 16,384 × 0.0183 / 5,040 ≈ 0.06 (6%).

E(Y) = λ | Variance: σ² = λ

PART 3: Continuous Distributions

When outcomes are infinite, we switch from bars to curves and from sums to areas. PDF, CDF, and the five key continuous distributions.

3.1 PDF and CDF: The New Toolkit

Probability Density Function (PDF): Written f(y), depicts the associated probability density for every possible value y. Its value is always ≥ 0. Its graph is the probability distribution curve.

Why Individual Values Have Probability Zero: With an infinite sample space, the denominator becomes enormous so the probability of any single exact value is essentially zero. Consequence: For continuous variables, P(Y > x) = P(Y ≥ x).

Cumulative Distribution Function (CDF): Written F(y) (capital F), represents the probability of the variable being less than or equal to a specific value: F(y) = P(Y ≤ y). Boundary values: F(-∞) = 0 and F(+∞) = 1.

Direction Operation
PDF → CDF Integrate the PDF from -∞ to y
CDF → PDF Take the first derivative of the CDF with respect to y
Probability of interval [A, B] Area under the PDF curve from A to B

Expected value = integral of y · f(y) over the interval from -∞ to +∞.

Variance = σ² = E(Y²) - [E(Y)]².

3.2 Normal Distribution: Nature's Favorite

NOTATION: X ~ N(μ, σ²)

When it applies: Natural phenomena and everyday life (e.g., weight of adult male lions averaging 150-250 kg).

Key Characteristics: Bell-shaped graph, symmetric about the mean, E(X) = μ.

The 68-95-99.7 Law: 68% within 1 SD, 95% within 2 SD, 99.7% within 3 SD.

3.3 Standardizing the Normal Distribution

A transformation alters every element to get a new distribution with similar characteristics.

  • Add constant: shifts graph right
  • Subtract constant: shifts graph left
  • Multiply by constant > 1: graph shrinks (tighter)
  • Divide by constant > 1: graph expands (wider)
Formula
Z = (Y - μ) / σ
Standardizing Z-score = (Value - Mean) / Standard Deviation. Transformed distribution has Mean = 0, Variance = 1.

WHEN NORMAL FAILS: With fewer than 30 entries, avoid assuming normality—use Student's T distribution instead.

3.4 Student's T Distribution: Normal's Small-Sample Cousin

NOTATION: Y ~ t(k) where k is degrees of freedom.

Bell-shaped and symmetric, but with fatter tails. Expected Value: E(Y) = μ (for k ≥ 2).

Formula
Variance = s² · [ k / (k - 2) ]
Student's T Variance = Sample Variance × [ Degrees of Freedom / (Degrees of Freedom - 2) ], for degrees of freedom k > 2.

3.5 Chi-Squared Distribution: The Statistician's Tool

NOTATION: Y ~ χ²(k)

Non-negative values only (starts from zero on left), highly skewed to the right.

Formula
E(Y) = k | Variance = 2k
Expected Value = Degrees of Freedom (k), Variance = 2 × Degrees of Freedom.

ACCURACY NOTE: Squaring a standard normal variable gives a chi-squared with 1 degree of freedom.

3.6 Exponential Distribution: Fast Early, Then Fading

NOTATION: X ~ Exp(λ)

Starts high, drops sharply, then plateaus (e.g., YouTube views).

Formula
E(X) = 1 / λ | Variance = 1 / λ²
Expected value (average time between events) = 1 / λ, Variance = 1 / λ².

THE LOG TRANSFORM: Taking the natural logarithm of exponential data makes it closer to normal and suitable for linear regressions.

3.7 Logistic Distribution: Forecasting a Cutoff

NOTATION: Y ~ Logistic(μ, s) where μ is location (mean) and s is scale parameter.

Determines how continuous inputs affect a binary outcome (e.g., tennis serve speed vs point outcome). CDF is S-shaped.

Formula
Variance = s² · π² / 3
Logistic Variance = scale² (s²) × π² / 3.

  • 4.2 Small Sample (Student's T): First 30 players show fatter tails, following Student's T distribution.
  • 4.3 Two Peaks (Bimodal Graph): Shot power shows two peaks due to goalkeepers having drastically different stats from outfield players.
  • 4.4 Player Ages (Poisson Distribution): Age starts at a minimum of 16 (youngest pro contract) and is right-skewed.
  • 4.5 Video Views (Exponential Distribution): Weekly promo views start at ~100k, drop to 20k, then plateau.

Quick Reference: PDF vs CDF & Empirical Rule Reference Matrix

PDF vs CDF Operations

• PDF f(x): Curve height (density). Area under entire curve = 1. P(X = x) = 0.
• CDF F(x): Cumulative P(X ≤ x) = ∫ f(t) dt from -∞ to x.
• Interval P(A ≤ X ≤ B): F(B) - F(A) = Area from A to B.

The Empirical 68-95-99.7 Rule

• μ ± 1σ: Exactly ~68.27% of all data.
• μ ± 2σ: Exactly ~95.45% of all data.
• μ ± 3σ: Exactly ~99.73% of all data (>3σ is an outlier).
