PART I - SETS AND EVENTS

1. Events as Sets

Every event has a set of outcomes that satisfy it. These are the favorable outcomes. For example, if the event is "rolling an even number," the set of values consists of 2, 4, 6, and so on. The values in a set do not have to be numerical.

Notation convention:

  • Uppercase letters denote sets: A, B, X.
  • Lowercase letters denote individual elements: a, b, x.

Empty and non-empty sets:

  • If it contains no values at all, we call it the empty set or null set, written Ø.
  • Non-empty sets are either finite or infinite, depending on how many elements they hold.

2. Set Notation

Symbol Read as Meaning
x ∈ A "x is an element of A" or "x in A" The value x belongs to set A
A ∋ x "A contains x" Same statement, written from the set's side
x ∉ A "x is not in A" The value x does not belong to A
A ¬∋ x "A does not contain x" Same statement, flipped
∀ "for all" or "for any" A capital A turned upside down
: "such that" Narrows a statement to a specific group
⊆ "is a subset of" Every element of the first set is in the second

Rule to remember: Every set contains at least two subsets, itself and the null set.

3. Visualizing Events

We draw the set of values satisfying an event as a circle. One circle per event. There are three possible relationships between circles:

  • Case 1: The circles never touch. The two events can never happen at the same time (e.g., drawing a diamond and a heart).
  • Case 2: The circles intersect. The two events can occur at the same time (e.g., drawing a diamond and a queen -> Queen of Diamonds).
  • Case 3: One circle completely contains the other. One event can only ever occur if the other one does as well (e.g., drawing a red card vs drawing a diamond). If an outcome is not part of a set, it cannot be part of any of its subsets.

4. Intersections

When we want both A and B to happen at the same time, we talk about their intersection (A ∩ B).

  • Circles do not touch: A ∩ B = Ø.
  • Circles intersect: A ∩ B holds whatever they share.
  • One circle inside the other: A ∩ B = B (the smaller set).

5. Unions

When we only require one of them to occur, regardless which, we talk about the union (A ∪ B).

Formula
A ∪ B = A + B - (A ∩ B)
Union (A or B) = Set A + Set B - Intersection (shared overlap)
  • Circles do not touch: Union is the plain sum of the two sets.
  • Circles intersect: Union is sum minus intersection (to prevent double-counting).
  • One circle inside the other: Union is simply the larger set.

6. Mutually Exclusive Sets and Complements

Definition

Mutually exclusive sets: Sets that have no overlapping elements (A ∩ B = Ø). Their union is simply the sum of individual sets.

Definition

Complements: All values that are part of the sample space but not part of the set.

Key Distinction: Complements are always mutually exclusive. But not all mutually exclusive sets are complements.

PART II - THE RULES OF PROBABILITY

7. Independent and Dependent Events

Definition

Independent events: Theoretical probabilities remain unaffected by other events (e.g., coin flip always 50% tails).

Definition

Dependent events: Probabilities vary as conditions change (e.g., drawing queen of spades drops sample space from 52 to 13 to 4).

Notation: P(A|B) reads "P of A given B" (conditional probability).

8. Computing Conditional Probability

Independence Test: P(A) = P(A|B). If knowing B changes nothing about A, the events are independent.

Formula
P(A|B) = P(A ∩ B) / P(B)
Conditional Probability of A given B = (Probability of both A and B occurring) / (Probability of B)

Order matters: P(A|B) is NOT the same as P(B|A), even when numeric values match.

9. The Law of Total Probability

Formula
P(A) = P(A|B₁)P(B₁) + P(A|B₂)P(B₂) + ...
Total Probability = Sum of conditional probabilities across all partition groups (B_i)

The probability of A is the sum of all conditional probabilities of A given B, each multiplied by the probability of that B.

10. The Additive Law

Formula
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
P(A ∩ B) = P(A) + P(B) - P(A ∪ B)
Addition & Overlap Rules:
• Union (A or B) = Probability of A + Probability of B - Intersection (A and B)
• Intersection (A and B) = Probability of A + Probability of B - Union (A or B)

11. The Multiplication Rule

Formula
P(A ∩ B) = P(A|B) × P(B) = P(B|A) × P(A)
Multiplication Rule (Both occur) = Conditional Probability × Given Probability

Taking a fraction of a fraction. For two draws without replacement (no spade first, spade second): P(A ∩ B) = 0.255 × 0.75 = 0.191 (19.1%).

PART III - BAYES AND BAYESIAN INFERENCE

12. Bayes' Theorem

Formula
P(A|B) = [ P(B|A) × P(A) ] / P(B)
Bayes' Theorem: Probability of A given B = [ Likelihood of B given A × Prior of A ] / Marginal probability of B

Bayes' theorem lets you find the relationship between two different conditional probabilities of a pair of events. Very often one direction is easy to measure and the other is what you care about.

13. From Formula to Way of Thinking

In Bayesian Inference:

  • H = Hypothesis: Something you are unsure about.
  • E = Evidence: Something you actually observed.
Formula
P(H|E) = [ P(E|H) × P(H) ] / P(E)
Bayesian Inference: Probability of Hypothesis given Evidence = [ Likelihood of Evidence given Hypothesis × Prior of Hypothesis ] / Total probability of Evidence

14. The Four Ingredients

Part Symbol Plain Meaning
Prior P(H) What you believed before seeing the evidence
Likelihood P(E|H) If the hypothesis were true, how likely is this evidence?
Evidence P(E) How likely is this evidence overall, under any hypothesis?
Posterior P(H|E) What you believe after seeing the evidence

15. Worked Example: Medical Test

Worked Example: Medical Test

Prevalence P(H) = 0.01; Sensitivity P(E|H) = 0.99; False Positive P(E|not H) = 0.05.

Evidence P(E) = (0.99 × 0.01) + (0.05 × 0.99) = 0.0594.

Posterior P(H|E) = (0.99 × 0.01) / 0.0594 = 0.167 (16.7%).

Base Rate Fallacy: Ignoring the prior when condition is rare leads to swamping true positives with false positives.

16. Spam Filter & 17. Sequential Updating

Worked Example: Spam Filter

Spam prior P(S) = 0.4; FREE in spam = 0.3; FREE in ham = 0.02

Posterior P(S|FREE) = 0.12 / 0.132 = 0.909 (90.9%).

Core Method

Sequential Updating Rule: "Today's posterior becomes tomorrow's prior." Updating with second word "WINNER" raises belief to 99.7%.

18. The Odds Form

Formula
Odds(H) = P(H) / P(Hᶜ)
Posterior Odds = Prior Odds × Likelihood Ratio
Likelihood Ratio (LR) = P(E|H) / P(E|Hᶜ)
Bayes' Theorem in Odds Form:
• Odds(H) = Probability of Hypothesis / Probability of Complement (not H)
• Likelihood Ratio (LR) = Likelihood of Evidence with Hypothesis / Likelihood of Evidence without Hypothesis

19. Three Mistakes to Avoid

  1. Confusing P(H|E) with P(E|H) (Prosecutor's fallacy).
  2. Ignoring the base rate.
  3. Treating the posterior as final.

Quick Reference: Bayes' Theorem Formula & 4 Core Ingredients

Bayes' Theorem Formula
P(A|B) = [ P(B|A) × P(A) ] / P(B)
Updates prior belief P(A) using new evidence B to compute posterior P(A|B).
1. Prior P(A)

Initial probability of hypothesis A before seeing evidence B.

2. Likelihood P(B|A)

Probability of observing evidence B given hypothesis A is true.

3. Marginal P(B)

Total probability of observing evidence B across all states.

4. Posterior P(A|B)

Updated probability of hypothesis A after incorporating evidence B.

Quick Reference: Common Bayesian Fallacies & Mistakes

Fallacy Name Common Mistake Correct Bayesian Rule
Base Rate Fallacy Ignoring the initial prior P(A) when evaluating positive test results. Always multiply likelihood by prior base rate P(A).
Transposed Conditional Assuming P(A|B) is equal to P(B|A). P(A|B) and P(B|A) are fundamentally different conditionals.

🧮 Part III (12–15): Bayes' Theorem, The Four Ingredients & Medical Diagnostic Test Worked Example
Calculate the true posterior probability P(H|E) of a condition given its baseline prior prevalence and diagnostic test accuracy (Sensitivity and False Positive rate).
Posterior Probability P(H|E): P(H|E) = 16.10%
Step-by-Step Bayesian Derivation:
• The 4 Ingredients: Prior P(H) = 0.0100 | Sensitivity P(E|H) = 0.9500 | False Positive P(E|¬H) = 0.0500 | Complement Prior P(¬H) = 0.9900
• Marginal Evidence P(E): [P(E|H) × P(H)] + [P(E|¬H) × P(¬H)] = (0.95 × 0.01) + (0.05 × 0.99) = 0.0095 + 0.0495 = 0.0590
• Posterior Probability P(H|E): [P(E|H) × P(H)] ÷ P(E) = 0.0095 ÷ 0.0590 = 0.1610 (16.10%)
• Base Rate Fallacy Warning: Even with a 95% accurate test, an individual testing positive has only a 16.10% true probability of possessing the rare condition because false positives swamp true positives in low-prevalence populations.
