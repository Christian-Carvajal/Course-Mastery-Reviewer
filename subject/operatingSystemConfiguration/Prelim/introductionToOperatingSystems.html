2. What is an Operating System?

Definition

An Operating System (OS) is system software that acts as an interface between the computer hardware and the user.

It Manages:

  • CPU
  • Memory
  • Storage
  • Input devices
  • Output devices
  • Software applications

The Operating System is the manager of the entire computer system.

Modern Gen (2000s–Present) Multi-Core CPUs & Mobile SoCs Cloud, Mobile, Virtualization & AI Hypervisors, mobile touch OS (Android/iOS), distributed cloud microservices & AI acceleration.

2. The 5 Core Operating System Management Functions

1. Process Management
CPU Scheduling & Concurrency
  • Runs Software: Executes user applications & background services.
  • Allocates CPU: Assigns CPU burst time using scheduling algorithms.
  • Schedules Processes: Context switches between active process threads.
2. Memory Management
RAM Allocation & Protection
  • Allocates RAM: Dynamically assigns primary memory space to active programs.
  • Protects Memory: Prevents processes from overwriting each other's memory blocks.
  • Shares Memory: Coordinates shared memory buffers for inter-process communication.
3. File Management
Hierarchical Storage & I/O
  • Stores & Organizes: Manages directories, folder paths, and file tables (NTFS, ext4).
  • Creates & Deletes: Allocates disk blocks for new files and reclaims deleted sectors.
  • Retrieves Data: Reads byte streams accurately from secondary storage drives.
4. Device Management
Peripheral Drivers & Buffering
  • Device Drivers: Communicates with hardware controllers (Keyboard, Mouse, GPU).
  • I/O Buffering: Smooths speed mismatches between fast CPU and slow peripherals.
  • Port Coordination: Manages USB, PCIe, Monitor output, and Printer spoolers.
5. Security & Protection
Authentication & Access Control
  • User Accounts: Manages unique credentials, identities, and admin groups.
  • Authentication: Validates passwords, biometric scans, and MFA tokens.
  • Permissions & Crypto: Enforces read/write/execute rights and encrypts storage.

3. Operating System Typology & Comparison Matrix

OS Type Core Definition & Behavior Key Characteristics Real-World Example
Batch OS Groups similar jobs into batches and executes sequentially without manual user intervention. High throughput for bulk data; zero interactive debugging during run. IBM OS/360, Payroll processing
Time-Sharing OS Allocates rapid CPU time slices (quanta) among multiple simultaneous users. Fast response time; multi-user interactive terminal support. Multics, UNIX, Linux servers
Distributed OS Coordinates a cluster of autonomous computers over a network to act as a single system. Resource sharing, fault tolerance, horizontal scalability. Apache Hadoop, Amoeba, Plan 9
Network OS (NOS) Provides specialized services (DNS, DHCP, Active Directory, file sharing) over a LAN. Centralized user management, print serving, robust security. Windows Server, Novell NetWare
Real-Time OS (RTOS) Guarantees task completion within strict, deterministic time deadlines. Hard RTOS (missed deadline = catastrophe) vs. Soft RTOS (degraded QoS). VxWorks, QNX, FreeRTOS (Medical/Aerospace)
Mobile OS Optimized for portable handheld touchscreens with power and thermal constraints. Touch UI, sensors (GPS/Gyro), cellular radios, aggressive battery management. Android (Google), iOS (Apple)
