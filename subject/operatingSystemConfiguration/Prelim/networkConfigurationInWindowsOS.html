2. What is Network Configuration?

Definition

Network Configuration is the process of setting up a computer's network settings so it can communicate with other devices and access the Internet.

It Includes:

  • IP Address
  • Subnet Mask
  • Default Gateway
  • DNS Server
  • Network Adapter Settings

Why is it Important?

  • ✔ Internet Access
  • ✔ File Sharing
  • ✔ Printer Sharing
  • ✔ Remote Access
  • ✔ Network Security

3. Basic Network Connection & Data Flow

Connection Chain: PC (Client) → Router (Gateway) → Internet

  • PC (Client): The PC generates data and sends it to the router.
  • Router (Gateway): The router receives the data, processes it, and forwards it to the Internet.
  • Internet: The data reaches the Internet and is delivered to the destination.
  • Data Flow: PC → Router → Internet

Network Topology (Office / Small Business Network Example)

  • Topology Type: Star Topology (All devices connect to a central device: Switch / Router / AP)
  • Router Functions: Routing / NAT, Firewall / Security, Acts as Default Gateway, DHCP Server (192.168.1.1)
  • IP Addressing Scheme:
    • Network Address: 192.168.1.0
    • Subnet Mask: 255.255.255.0
    • Default Gateway: 192.168.1.1 (Router)
    • DHCP Range: 192.168.1.100 192.168.1.200
    • DNS Server: 8.8.8.8 (Google DNS) | 1.1.1.1 (Cloudflare DNS)

4. Basic Network Components

  • IP Address: A unique address assigned to every device. Example: 192.168.1.100
  • Subnet Mask: Determines the network and host portions. Example: 255.255.255.0
  • Default Gateway: Allows communication outside the local network. Example: 192.168.1.1
  • DNS Server: Translates website names into IP addresses.
    • Google DNS Example: 8.8.8.8
    • Cloudflare DNS Example: 1.1.1.1

5. Static vs. Dynamic IP Address & DHCP

Static vs Dynamic IP Address

Feature Static IP Dynamic IP (DHCP)
ConfigurationManual ConfigurationAutomatic Configuration
Address TypePermanent AddressTemporary Address
Used byUsed by ServersUsed by Home PCs
ManagementLess FlexibleEasy to Manage

DHCP (Dynamic Host Configuration Protocol)

Automatically assigns:

  • IP Address
  • Subnet Mask
  • Gateway
  • DNS

Interaction Flow: DHCP Client requests "I need an IP Address" → Router / DHCP Server assigns "Here's your IP Address 192.168.1.100"

Configuration Notes

  • Dynamic IP (DHCP): Automatically assigns network settings from a DHCP server. Recommended for most home and office users.
  • Static IP: Manually configured and commonly used for servers, printers, and network devices that require a fixed address.
  • DNS Server: Converts domain names (such as www.google.com) into IP addresses so users can access websites.
  • Static IP Warning: When configuring a static IP address, always ensure it belongs to the correct network and does not duplicate another device's IP address to avoid address conflicts.

8. Network Diagnostic Commands: Ping

The ping command is one of the first tools used by IT professionals to verify network connectivity and troubleshoot communication problems.

ping 8.8.8.8
ping google.com

Ping Output Breakdown

  • Reply from: The destination device responded successfully.
  • bytes=32: Size of each packet sent.
  • time=18ms: Round-trip time; lower values indicate a faster connection.
  • TTL (Time To Live): Limits how many network devices (hops) a packet can pass through before being discarded.
  • Packets Sent/Received/Lost: Indicates whether the connection is reliable. A 0% loss means all packets reached the destination successfully.

Common Ping Results

Result Meaning
✅ Reply from...Connection is successful.
❌ Request timed outThe destination did not respond.
❌ Destination host unreachableThe computer cannot reach the target network or device.
❌ Ping request could not find hostDNS could not resolve the hostname.

9. Configuring IPv4 Settings

Method 1: Using Windows Settings (Windows 11)

  1. Open Settings.
  2. Select Network & Internet.
  3. Click Ethernet or Wi-Fi.
  4. Select your active network connection.
  5. Under IP Assignment, click Edit.
  6. Choose Manual and enable IPv4.
  7. Enter the network information, then click Save.

Setting Example Values

SettingExample Value
IP Address192.168.1.100
Subnet Mask255.255.255.0
Default Gateway192.168.1.1
Preferred DNS8.8.8.8
Alternate DNS1.1.1.1

Legacy Method (Control Panel)

  1. Open Control Panel.
  2. Go to Network and Sharing Center.
  3. Click Change adapter settings.
  4. Right-click the active network adapter and select Properties.
  5. Double-click Internet Protocol Version 4 (TCP/IPv4).
  6. Select either:
    • 1. Obtain an IP address automatically (DHCP), or
    • 2. Use the following IP address (Static IP).
  7. Enter the required IP configuration and click OK.

🏛️ Pillar 1: Core Terminology & Keyword Recall Grid

Crucial networking terms, address types, and diagnostic protocols for rapid exam retrieval.

Term / Concept Category Exact Academic Definition Exam Trigger / High-Yield Keyword
Network Configuration Networking The process of assigning IP addresses, subnet masks, default gateways, DNS servers, and adapter settings to enable communication across a computer network. IP, Mask, Gateway, DNS, Adapter setup
IPv4 Address Addressing A 32-bit logical numerical identifier represented as four 8-bit octets in dotted-decimal notation (0–255), uniquely identifying a device interface on an IP network. 32 bits, 4 octets, Dotted-decimal, Logical address
Subnet Mask Addressing A 32-bit bitmask that separates the Network ID portion of an IP address from the Host ID portion by setting all network bits to contiguous 1s and host bits to 0s. Separates Network vs Host portion, Bitwise AND mask

🧮 Pillar 2: Formula & Calculation Reference Cards

Subnetting equations, host capacity formulas, bitwise masks, and hop decrement math with plain English verbalizations.

Subnet Host Capacity
Nusable_hosts = 2h − 2 = 2(32 − CIDR) − 2
Variable Legend:
• h: Number of unmasked host bits (32 − CIDR prefix length).
• − 2: Subtracts Network ID (all 0s) and Broadcast Address (all 1s).
Plain English Verbalization:
"The count of assignable host devices per subnet is two raised to the power of host bits minus two, because all-zero host bits designate the Network ID and all-one host bits designate the Broadcast Address."
🗣️ How to Read in English
Read as: "Usable hosts per subnet equals two raised to the host bits minus two (subtracting network ID and broadcast address)."
Bitwise Network ID
Network ID = Host IPv4 Address & Subnet Mask
Bitwise Logic:
• 1 & 1 = 1 (Preserves network prefix bits).
• x & 0 = 0 (Forces all host bits to binary 0).
Plain English Verbalization:
"Performing a binary logical AND operation between any host IP address and its subnet mask extracts the base Network ID by filtering out the host portion."
🗣️ How to Read in English
Read as: "The Network ID is computed by performing a bitwise AND between the IPv4 address and the subnet mask."
Broadcast Calculation
Broadcast Address = Network ID | ( ∼Subnet Mask )
Variable Legend:
• ∼Subnet Mask: The Wildcard Mask (inverted bits: 255.255.255.0 → 0.0.0.255).
• |: Bitwise OR operation setting all host bits to 1.
Plain English Verbalization:
"Combining the Network ID with the inverted wildcard mask via logical OR sets every host bit to 1, producing the subnet's directed broadcast address."
🗣️ How to Read in English
Read as: "The Broadcast Address is computed by setting all host bits to binary 1 (bitwise OR with the inverted mask)."
Subnet Division
Nsubnets = 2b
Variable Legend:
• b: Number of bits borrowed from the default classful host portion.
• Example: Borrowing 3 bits from /24 → /27 yields 23 = 8 subnets.
Plain English Verbalization:
"The total number of independent subnets created equals two raised to the power of borrowed network bits."
🗣️ How to Read in English
Read as: "The number of created subnets equals two raised to the borrowed subnet bits b."
CIDR Mask Map
/24=.0 | /25=.128 | /26=.192 | /27=.224 | /28=.240 | /29=.248 | /30=.252
Bit Weight Derivation:
• 1 bit = 128, 2 bits = 192, 3 bits = 224, 4 bits = 240, 5 bits = 248, 6 bits = 252.
Plain English Verbalization:
"Every additional masked bit in the 4th octet adds descending powers of two (128, 64, 32, 16, 8, 4), reducing host capacity by half at each step."
🗣️ How to Read in English
Read as: "Slash-24 has 256 addresses; /25 has 128; /26 has 64; /27 has 32; /28 has 16; /29 has 8; /30 has 4 (2 usable)."
Packet Lifespan
Remaining TTL = Initial TTL − Total Router Hops
Operational Rule:
• Default initial TTL: Windows = 128, Linux/macOS = 64, Cisco IOS = 255.
• If Remaining TTL reaches 0 → Router drops packet and returns ICMP Type 11.
Plain English Verbalization:
"Each Layer 3 router decrements the TTL field by exactly 1; subtracting final ping TTL from default TTL reveals total traversed network hops."
🗣️ How to Read in English
Read as: "The remaining Time To Live in an IP packet equals its initial TTL minus the total number of intermediate router hops traversed."

⚠️ Pillar 4: Common Exam Pitfalls & Fallacies

Crucial subnetting traps, APIPA misconceptions, DNS isolation diagnostics, and gateway subnet boundary rules.

🚫 Pitfall 1: Forgetting the "-2" Host Subnetting Rule

The Trap: Calculating usable hosts as 2h instead of 2h − 2.
The Truth: In any IPv4 subnet, the first address (host bits all 0s) is strictly reserved for the Network ID, and the last address (host bits all 1s) is reserved for the Directed Broadcast Address. A /24 subnet has 256 total IP states, but only 254 usable host interfaces.

🚫 Pitfall 2: APIPA 169.254.x.x Means DHCP Has Failed!

The Trap: Believing a computer with IP 169.254.45.100 is connected to the Internet.
The Truth: Any IP starting with 169.254. is an APIPA address automatically assigned by Windows when its DHCP request timed out without receiving a reply. It allows communication only with peers on the same physical switch wire; it cannot route to the Internet because there is no Default Gateway.

🚫 Pitfall 3: Default Gateway MUST Match the Host's Subnet

The Trap: Setting host IP to 192.168.1.50/24 and Default Gateway to 192.168.2.1.
The Truth: A host cannot forward packets to a gateway that resides in a different logical network. The Default Gateway must belong to the exact same IP subnet as the host's own IP address (e.g. Gateway 192.168.1.1 on 192.168.1.0/24).

🚫 Pitfall 4: Isolating DNS vs IP Routing Failures

The Trap: Assuming the Internet connection is broken when ping google.com fails.
The Truth: Always test numerical IP ping first: if ping 8.8.8.8 succeeds, your Layer 3 physical link, IP routing, and default gateway are 100% operational. Failure of ping google.com isolates the problem strictly to DNS server name resolution (fix with ipconfig /flushdns or changing DNS server).
