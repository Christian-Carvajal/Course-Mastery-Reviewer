2. What is Network Configuration?

Definition

Network Configuration is the process of setting up a computer's network settings so it can communicate with other devices and access the Internet.

It Includes:

  • IP Address
  • Subnet Mask
  • Default Gateway
  • DNS Server
  • Network Adapter Settings

Why is it Important?

  • ✔ Internet Access
  • ✔ File Sharing
  • ✔ Printer Sharing
  • ✔ Remote Access
  • ✔ Network Security

3. Basic Network Connection & Data Flow

Connection Chain: PC (Client) → Router (Gateway) → Internet

  • PC (Client): The PC generates data and sends it to the router.
  • Router (Gateway): The router receives the data, processes it, and forwards it to the Internet.
  • Internet: The data reaches the Internet and is delivered to the destination.
  • Data Flow: PC → Router → Internet

Network Topology (Office / Small Business Network Example)

  • Topology Type: Star Topology (All devices connect to a central device: Switch / Router / AP)
  • Router Functions: Routing / NAT, Firewall / Security, Acts as Default Gateway, DHCP Server (192.168.1.1)
  • IP Addressing Scheme:
    • Network Address: 192.168.1.0
    • Subnet Mask: 255.255.255.0
    • Default Gateway: 192.168.1.1 (Router)
    • DHCP Range: 192.168.1.100 192.168.1.200
    • DNS Server: 8.8.8.8 (Google DNS) | 1.1.1.1 (Cloudflare DNS)

4. Basic Network Components

  • IP Address: A unique address assigned to every device. Example: 192.168.1.100
  • Subnet Mask: Determines the network and host portions. Example: 255.255.255.0
  • Default Gateway: Allows communication outside the local network. Example: 192.168.1.1
  • DNS Server: Translates website names into IP addresses.
    • Google DNS Example: 8.8.8.8
    • Cloudflare DNS Example: 1.1.1.1

DHCP (Dynamic Host Configuration Protocol)

Automatically assigns:

  • IP Address
  • Subnet Mask
  • Gateway
  • DNS

Interaction Flow: DHCP Client requests "I need an IP Address" → Router / DHCP Server assigns "Here's your IP Address 192.168.1.100"

Configuration Notes

  • Dynamic IP (DHCP): Automatically assigns network settings from a DHCP server. Recommended for most home and office users.
  • Static IP: Manually configured and commonly used for servers, printers, and network devices that require a fixed address.
  • DNS Server: Converts domain names (such as www.google.com) into IP addresses so users can access websites.
  • Static IP Warning: When configuring a static IP address, always ensure it belongs to the correct network and does not duplicate another device's IP address to avoid address conflicts.

8. Network Diagnostic Commands: Ping

The ping command is one of the first tools used by IT professionals to verify network connectivity and troubleshoot communication problems.

ping 8.8.8.8
ping google.com

Ping Output Breakdown

  • Reply from: The destination device responded successfully.
  • bytes=32: Size of each packet sent.
  • time=18ms: Round-trip time; lower values indicate a faster connection.
  • TTL (Time To Live): Limits how many network devices (hops) a packet can pass through before being discarded.
  • Packets Sent/Received/Lost: Indicates whether the connection is reliable. A 0% loss means all packets reached the destination successfully.

Common Ping Results

Result Meaning
✅ Reply from...Connection is successful.
❌ Request timed outThe destination did not respond.
❌ Destination host unreachableThe computer cannot reach the target network or device.
❌ Ping request could not find hostDNS could not resolve the hostname.

9. Configuring IPv4 Settings

Method 1: Using Windows Settings (Windows 11)

  1. Open Settings.
  2. Select Network & Internet.
  3. Click Ethernet or Wi-Fi.
  4. Select your active network connection.
  5. Under IP Assignment, click Edit.
  6. Choose Manual and enable IPv4.
  7. Enter the network information, then click Save.

Setting Example Values

SettingExample Value
IP Address192.168.1.100
Subnet Mask255.255.255.0
Default Gateway192.168.1.1
Preferred DNS8.8.8.8
Alternate DNS1.1.1.1

Legacy Method (Control Panel)

  1. Open Control Panel.
  2. Go to Network and Sharing Center.
  3. Click Change adapter settings.
  4. Right-click the active network adapter and select Properties.
  5. Double-click Internet Protocol Version 4 (TCP/IPv4).
  6. Select either:
    • 1. Obtain an IP address automatically (DHCP), or
    • 2. Use the following IP address (Static IP).
  7. Enter the required IP configuration and click OK.

Quick Reference: Windows Network Configuration & Diagnostic Commands

1. Windows CLI Diagnostic & Configuration Command Matrix

Command Syntax Primary Action & Purpose Output / Key Parameters
ipconfig Displays quick summary of active network adapters. IPv4 Address, Subnet Mask, Default Gateway.
ipconfig /all Displays exhaustive configuration for all physical & virtual adapters. Physical MAC Address, DHCP Server, DNS Servers, Lease Obtained/Expires, Host Name.
ipconfig /release Drops active DHCP lease and clears the current IP address. IPv4 set to 0.0.0.0; informs DHCP server that address is freed.
ipconfig /renew Requests a fresh IP address and lease parameters from DHCP server. Triggers DHCP Discover/Request; assigns new IP configuration.
ipconfig /flushdns Purges and resets the contents of the local DNS resolver cache. Removes stale/outdated DNS IP records; forces new DNS lookups.
ping <target> Tests Layer 3 network reachability using ICMP Echo Requests. Round-trip time (latency in ms), Packet loss %, TTL (Time To Live).
ping 127.0.0.1 Tests local TCP/IP stack integrity (Loopback Test). Confirms network card and OS protocol stack are functioning without leaving PC.
tracert <target> Traces the exact router hop path packets take to destination. Lists intermediate router IPs and millisecond response times per hop.
nslookup <domain> Queries DNS name servers to resolve domain names to IP addresses. Server IP, Non-authoritative answer, resolved IPv4/IPv6 addresses.

2. IPv4 Address Classes & Special Purpose Addresses

Class A
1.0.0.0 – 126.255.255.255

Default Mask: 255.0.0.0 (/8)
Network / Host: 8 bits Net, 24 bits Host (16.7M hosts/net).
Private Range: 10.0.0.0 – 10.255.255.255 (Large Enterprise).

Class B
128.0.0.0 – 191.255.255.255

Default Mask: 255.255.0.0 (/16)
Network / Host: 16 bits Net, 16 bits Host (65,534 hosts/net).
Private Range: 172.16.0.0 – 172.31.255.255 (Medium Enterprise).

Class C
192.0.0.0 – 223.255.255.255

Default Mask: 255.255.255.0 (/24)
Network / Host: 24 bits Net, 8 bits Host (254 hosts/net).
Private Range: 192.168.0.0 – 192.168.255.255 (Home & Small LAN).

Special & Reserved Addresses
Loopback & APIPA

127.0.0.1: Local Loopback (Internal TCP/IP test).
169.254.x.x: APIPA (Automatic Private IP when DHCP fails).
255.255.255.255: Limited Local Broadcast.
8.8.8.8 & 1.1.1.1: Public DNS (Google & Cloudflare).
